## 给写作 agent 的使用方法

1. 精读 `chapters/P05-P05｜Session 与恢复.md` 已完成部分，学习领域边界、朴素方案失效和行业设计空间的论证方式；
2. 读要写的章节旧稿和最新 `main` 对应源码，旧稿只提供历史素材，当前事实以源码和测试为准；
3. P04 与 P05 都是写作参考，不是章节模板；每章应对应 Agent 应用或 Harness 需要独立设计的一个领域；
4. 具体写作约束由对话中的 prompt 提供。

## 维护

- 重新抓取文本：使用 `lark-cli docs +fetch`，并在章节顶部记录飞书 revision；
- 仓库只保存文本和绘图提示词，不提交飞书图片或其他报告资产；
- 远程写作 agent 只能依赖 GitHub 可访问的仓库和公开资料，不应收到本机绝对路径。
