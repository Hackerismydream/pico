## 给写作 agent 的使用方法

1. 精读 `chapters/P04-P04｜Pico的上下文工程.md` 全文 + 它对应的图，学它的进入方式、论证推进和"为什么"决策问答；
2. 读要写的章节当前 md（内容素材）和对应源码（仓库 `pico/` 下）；
3. 写作时以 P04 为风格参考，但不要逐节照搬它的章节形状，按每章主题自由组织；
4. 具体写作约束由对话中的 prompt 提供。
